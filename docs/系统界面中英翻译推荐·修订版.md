## 1. 翻译范围与总原则

英文模式下，**翻译系统界面和交互提示，不翻译书籍正文与传统文化内容**。英文切换只改变界面外壳，不改变书名、原文、注疏、引文、人物介绍、对话内容、学习记录和生成内容。

| 内容类型 | 英文模式下的处理方式 | 示例 |
| --- | --- | --- |
| 导航、页面标题、按钮、表单、状态提示、错误信息 | 切换为英文 | 典籍书库 → Classics Library |
| 书名、书籍正文、注疏、原文白话解释 | 保持中文 | 《论语·学而》1.1 |
| 孔子及弟子姓名、生平、原文对白 | 保持中文；可在英文辅助文本中使用拼音 | 孔子、颜回、子路 |
| 印章、品牌字标、竖排装饰字 | 保持中文 | 論語、日課 |
| 用户输入、AI 回答、人物生成回答 | 保持实际生成语言，前端不自动改写 | 用户输入的讨论内容 |
| 性格测试、上传说明、声音选项等操作型文案 | 翻译，否则英文用户无法完成创作流程 | 性格测试 → Personality Quiz |

### 1.2 英文界面书写规范

1. 短按钮和标签使用 sentence case，例如 **Ask a question**，不全部大写。
2. 页面标题首字母大写；正文句子使用正常英文标点。
3. 按钮优先控制在 1～3 个单词，例如 **Start a chat**、**Generate portrait**。
4. 短标签末尾不加句号；完整提示句可以加句号。
5. 英文模式不使用中文全角标点，但书名、原文、引文和印章保持原样。
6. 动态数量使用英语单复数规则，较正式位置使用 `1 member / 2 members`。
7. 品牌主字标“智启论语”建议作为文化标识保留；页面标题、导航和操作性文字切换为英文。
8. 不使用国旗表示语言，国旗代表国家，不等于语言。
9. 🔧新增：古籍一律用 **work / classic work**，不完全依赖 book（见第 5、13 章）。

## 12. 英文界面的显示与可读性建议

### 12.1 版式

1. 英文按钮和导航标签不要沿用中文的大字距。中文的 `.16em`～`.2em` 字距会让英语词组显得松散。
2. 英文标题使用正常字距，建议 `letter-spacing: -0.01em` 到 `0.02em`。
3. 短按钮允许自然换行，避免为中文固定宽度；建议设置 `min-height` 和自适应 `padding`。
4. 英文导航推荐保持以下短词：

```text
Home | Library | AI Q&A | Sages | Studio | Account
```

5. 较长的完整名称放在页面标题中，不在顶部导航中使用，例如导航用 `Studio`，页面标题用 `Moral Fibre & Aesthetic-Bearing Studio`。
6. 竖排文字、印章和中文书名保持原有版式；英文说明使用横排，不把英文强行塞入竖排区域。
7. 英文模式可以保留中文品牌字标和文化装饰字，但按钮、状态和帮助文字必须使用英文。
8. 按钮内英文一般不超过 24 个字符；页面说明每行建议 50～75 个字符。
9. 移动端优先保留按钮图标和短标签，必要时隐藏重复的英文副标题。
10. 不要把英文全部转成大写；长段全大写会显著降低可读性。

### 12.2 字体

建议在 `<html lang="en">` 下单独设置英文字体栈：

```css
html[lang="en"] body {
  font-family: "Source Serif 4", "Noto Serif", Georgia, serif;
}

html[lang="en"] .menu a,
html[lang="en"] .btn,
html[lang="en"] .tag,
html[lang="en"] .note {
  letter-spacing: 0.01em;
  text-transform: none;
}

html[lang="en"] .hero-title {
  letter-spacing: -0.015em;
  line-height: 1.08;
}
```

书名、原文和人物姓名仍使用支持中文的字体栈，并为 `zh-CN` 与 `en` 分别设置合理的 `font-family`。

### 12.3 语言状态与本地保存

1. 切换语言时同步更新：

```text
document.documentElement.lang = "zh-CN" | "en";
```

2. 语言选择保存到 `localStorage`，刷新后沿用。
3. 页面标题、`meta description`、按钮 `title`、`aria-label` 和占位符都要随语言切换。
4. 切换语言后重新渲染当前页面，但保留当前路由、会话、收藏、表单内容与用户输入。
5. 书籍请求始终使用原有中文书名 ID，不能把英文显示名传给 `/api/book?name=`。
6. 先完成界面翻译，不做浏览器自动整页翻译，避免“典籍书库”等词被翻译成不稳定的浏览器译文。

### 13.1 可选的双语辅助方式

为了帮助外国学生，同时不改变书籍内容，可在以下位置增加辅助信息：

- 书名旁增加小号英文标签，例如：`《论语》` 下方显示 `The Analects`。
- 人物名称保持中文，资料卡增加拼音，例如：`颜回 / Yan Hui`。
- 文章出处保持中文，预览或悬浮说明中增加英文解释。
- 为关键文化词设置首次出现的简短英文 tooltip，例如：`仁 / ren (benevolence)`。

这些辅助文字应作为“释义层”，不能覆盖或替换中文正文。
